# Quality Assurance Workflow

## QA Review Process

My Quality Assurance contribution followed a structured review process across the project's documentation.

```text
        PROJECT DOCUMENT
               │
               ▼
        CONTENT REVIEW
               │
               ▼
       ACCURACY CHECK
               │
               ▼
     FORMATTING & CONSISTENCY
               │
               ▼
      REFERENCE CHECK
               │
               ▼
      SPELLING & GRAMMAR
               │
               ▼
       VERSION CONTROL
               │
               ▼
       FINAL INTEGRATION
               │
               ▼
       SUBMISSION REVIEW
```

## Review Areas

| Review Area     | Objective                                       |
| --------------- | ----------------------------------------------- |
| Content         | Identify incomplete or inconsistent information |
| Accuracy        | Verify project information and tables           |
| Formatting      | Maintain consistent document presentation       |
| Referencing     | Check APA 7 requirements                        |
| Grammar         | Identify spelling and language issues           |
| Version Control | Ensure the appropriate document version is used |
| Integration     | Check consistency between deliverables          |
| Final Review    | Confirm readiness for submission                |

## Practical Application

The QA review process was applied to multiple project outputs, including the Scope document, Methodology document, Gantt Chart, and Final Report draft.

The process demonstrated how structured quality checks can support collaborative project delivery.
