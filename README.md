## Key Learning

The project demonstrated that effective project management depends on integrating multiple areas rather than managing them independently.

For example:

**Scope → WBS → Activities → Schedule → Resources → Risk → Communication → Quality → Delivery**

A change in one area can affect several other project dimensions. This experience strengthened my understanding of project integration, structured planning, quality control and systems thinking.
